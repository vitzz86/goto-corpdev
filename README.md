# GoTo Corporate Development Cockpit

Live dashboard: https://vitzz86.github.io/goto-corpdev/

An independent interview demonstration combining a decision brief, listed-market charts, economic indicators, financial and valuation context, corporate actions, an ecosystem map, an investment-route register, competitor monitoring, deal sourcing, a news feed and a research / investor-relations library.

Research snapshot: 13 October 2026. Source dates, reviewed evidence, secondary provider classifications, reference research and RSS discovery leads remain labelled. Strategic implications are analyst interpretations. Private stakes, fund allocation and attributable NAV are not inferred.

This is a static dashboard. TradingView widgets retrieve provider content; the curated research snapshot is refreshed through research and republishing. Browser notes and watchlists stay local. The weekly chat monitor is separate.

This repository hosts only the dedicated goto-corpdev project page. It does not modify the vitzz86.github.io main website.
